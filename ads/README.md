# Colony Food Market video ads

| File | Format | Length | Language |
|---|---|---|---|
| `colony-food-market-ad.mp4` | vertical 1080×1920 (Reels, TikTok, Stories, WhatsApp status) | 35 s | English + Spanish |
| `colony-food-market-ad-square.mp4` | square 1080×1080 (Facebook / Instagram feed) | 35 s | English + Spanish |
| `colony-food-market-ad-papiamento.mp4` | vertical 1080×1920 | 35 s | Papiamento |
| `colony-food-market-ad-15s.mp4` | vertical 1080×1920 | 15 s | English + Spanish |

The music is original (generated by `music.py`), so it is free to use on any platform.

## Rebuilding

Everything comes from `colony-ad.html` (texts are in the `T` object near the bottom). Options: `?lang=enes|pa`, `?fmt=vertical|square`, `?cut=full|short`.

```sh
# from the repository root
python3 -m http.server 8765 &
ffmpeg -ss 3.4 -t 3.6 -i assets/dance-challenge-video.mp4 -vf "fps=30,scale=420:-2" -q:v 6 ads/clip/f%03d.jpg   # store footage frames (mkdir ads/clip first)
python3 ads/music.py music.wav 35.4          # needs numpy + scipy; use 15 for the short cut
node ads/render.js "http://localhost:8765/ads/colony-ad.html?fmt=square" silent.mp4   # needs playwright + ffmpeg
ffmpeg -i silent.mp4 -i music.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart out.mp4
```
